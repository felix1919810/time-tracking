## 1. 技术架构

### 1.1 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 数据存储 | 飞书多维表格 | 零运维、原生可视化、团队协作 |
| 后端框架 | Python FastAPI | 异步性能好、自带 OpenAPI 文档、飞书 SDK 支持完善 |
| 飞书 SDK | lark-oapi (Python) | 官方维护、token 自动刷新、类型完善 |
| 定时任务 | APScheduler | 轻量、支持 cron 表达式、与 FastAPI 集成简单 |
| 前端框架 | H5 + Vue 3（或原生） | 飞书网页应用支持 H5 嵌入 |
| 消息推送 | 飞书 im/v1 API | 原生消息卡片交互 |
| 配置管理 | Pydantic Settings + .env | 类型安全、环境隔离 |

## 2. 数据模型

### 2.1 clients 客户表

| 字段名 | 字段类型 | 是否必填 | 说明 |
|---|---|---|---|
| 客户名称 | 多行文本 | 是 | 唯一 |
| 联系人 | 多行文本 | 否 | |
| 邮箱 | 多行文本 | 否 | |
| 状态 | 单选 | 是 | active / archived |
| 创建时间 | 创建时间 | 自动 | 系统字段 |

### 2.2 projects 项目表

| 字段名 | 字段类型 | 是否必填 | 说明 |
|---|---|---|---|
| 项目名称 | 多行文本 | 是 | |
| 客户 | 关联 clients | 否 | 单选关联 |
| 颜色 | 单选 | 是 | blue/green/red/yellow/purple/orange |
| 是否计费 | 复选框 | 是 | 默认否 |
| 预估工时 | 数字 | 否 | 单位：小时，用于超额检测 |
| 状态 | 单选 | 是 | active / archived |
| 创建时间 | 创建时间 | 自动 | |

### 2.3 tags 标签表

| 字段名 | 字段类型 | 是否必填 | 说明 |
|---|---|---|---|
| 标签名称 | 多行文本 | 是 | 唯一 |
| 创建时间 | 创建时间 | 自动 | |

### 2.4 time_entries 时间条目表（核心）

| 字段名 | 字段类型 | 是否必填 | 说明 |
|---|---|---|---|
| 描述 | 多行文本 | 否 | 任务描述 |
| 项目 | 关联 projects | 否 | 单选关联 |
| 标签 | 多选关联 tags | 否 | 多选关联 |
| 开始时间 | 日期（带时分秒） | 是 | 毫秒时间戳 |
| 结束时间 | 日期（带时分秒） | 否 | running 状态时为空 |
| 时长(秒) | 数字 | 是 | 停止时自动计算，running 时为 0 |
| 用户 | 人员 | 是 | 计时人 open_id |
| 是否计费 | 复选框 | 是 | 默认继承项目 |
| 状态 | 单选 | 是 | running / stopped |

### 2.5 实体关系

```
clients (1) ──── (N) projects
                      │
                      │ (1)
                      │
                      ▼
tags (N) ←── (N) time_entries (N) ──→ (1) projects
                      │
                      │
                      ▼
                   users (open_id)
```

## 3. 接口设计

### 3.1 计时器接口

#### POST /api/timer/start — 开始计时

**请求体**：
```json
{
  "user_id": "ou_xxxxxxxxxxxxxxxx",
  "description": "编写用户登录模块",
  "project_id": "recxxxxxxxxxx",
  "tags": ["后端", "紧急"],
  "billable": true,
  "start_at_ms": 1723920000000
}
```

**响应**：
```json
{
  "ok": true,
  "entry": {
    "record_id": "recxxxxxxxxxx",
    "fields": {
      "描述": "编写用户登录模块",
      "开始时间": 1723920000000,
      "状态": "running",
      "时长(秒)": 0
    }
  }
}
```

#### POST /api/timer/stop — 停止计时

**请求体**：
```json
{
  "record_id": "recxxxxxxxxxx",
  "stop_at_ms": 1723951200000
}
```

**响应**：
```json
{
  "ok": true,
  "entry": {
    "record_id": "recxxxxxxxxxx",
    "start_ms": 1723920000000,
    "stop_ms": 1723951200000,
    "duration_sec": 31200
  }
}
```

#### GET /api/timer/current — 获取当前进行中条目

**查询参数**：`user_id`（必填）

**响应**：
```json
{
  "ok": true,
  "entry": {
    "record_id": "recxxxxxxxxxx",
    "fields": {
      "描述": "编写用户登录模块",
      "开始时间": 1723920000000,
      "状态": "running"
    }
  }
}
```

### 3.2 项目接口

#### POST /api/projects — 创建项目

**请求体**：
```json
{
  "name": "飞书时间追踪",
  "client_id": "recyyyyyyyyyy",
  "color": "blue",
  "billable": true,
  "estimated_hours": 160
}
```

#### GET /api/projects — 列出项目

**查询参数**：`status`（active | archived | all，默认 active）

#### PATCH /api/projects/{id} — 更新项目

**请求体**（部分字段）：
```json
{
  "name": "改名后的项目",
  "estimated_hours": 200
}
```

#### POST /api/projects/{id}/archive — 归档项目

#### DELETE /api/projects/{id} — 删除项目

### 3.3 时间条目接口

#### POST /api/entries — 手动添加工时

**请求体**：
```json
{
  "user_id": "ou_xxxxxxxxxxxxxxxx",
  "description": "需求评审会议",
  "project_id": "recxxxxxxxxxx",
  "tags": ["会议"],
  "billable": false,
  "start_at_ms": 1723920000000,
  "stop_at_ms": 1723923600000
}
```

#### GET /api/entries — 列出时间条目

**查询参数**：
- `user_id`（可选）
- `project_id`（可选）
- `start_ms`（可选，筛选开始时间下限）
- `end_ms`（可选，筛选结束时间上限）
- `limit`（默认 100，最大 500）

#### PATCH /api/entries/{id} — 更新条目

#### DELETE /api/entries/{id} — 删除条目

### 3.4 报表接口

#### GET /api/reports/weekly — 周报

**查询参数**：`user_id`（可选）

**响应**：
```json
{
  "ok": true,
  "report": {
    "period": "week",
    "start_date": "2026-08-17",
    "end_date": "2026-08-23",
    "total_sec": 144000,
    "entry_count": 25,
    "by_project": [
      {"project_id": "recxxx", "project_name": "项目A", "total_sec": 72000, "count": 12}
    ],
    "by_tag": [
      {"tag_name": "后端", "total_sec": 80000, "count": 15}
    ],
    "by_date": [
      {"date": "2026-08-17", "total_sec": 28800, "count": 5}
    ]
  }
}
```

#### GET /api/reports/monthly — 月报

#### GET /api/reports/custom — 自定义时间范围

**查询参数**：`start_ms`、`end_ms`、`user_id`（可选）

#### GET /api/reports/export — 导出 CSV

**查询参数**：同 custom

**响应**：`text/csv` 文件下载

### 3.5 提醒接口

#### POST /api/notify/text — 发送纯文本消息

**请求体**：
```json
{
  "text": "你好，这是一条测试消息",
  "receive_id": "oc_xxxxxxxxxxxxxxxx",
  "receive_id_type": "chat_id"
}
```

#### POST /api/notify/card — 发送消息卡片

**请求体**：
```json
{
  "card": {
    "config": {"wide_screen_mode": true},
    "header": {
      "title": {"tag": "plain_text", "content": "今日工时报表"},
      "template": "blue"
    },
    "elements": [
      {"tag": "div", "text": {"tag": "lark_md", "content": "**总工时**: 8h 30m"}}
    ]
  }
}
```

#### POST /api/notify/daily — 手动触发日报推送

#### POST /api/notify/weekly — 手动触发周报推送

#### POST /api/notify/running — 手动触发未停止计时器检测

#### POST /api/notify/overrun — 手动触发工时超额检测

### 3.6 飞书回调接口

#### POST /api/lark/webhook — 飞书事件订阅入口

**URL 验证请求**：
```json
{
  "challenge": "ajls384kdjx98XX",
  "token": "xxxxxx",
  "type": "url_verification"
}
```

**消息事件**：
```json
{
  "schema": "2.0",
  "header": {
    "event_id": "xxx",
    "event_type": "im.message.receive_v1",
    "token": "verification_token",
    "app_id": "cli_xxx",
    "tenant_key": "xxx"
  },
  "event": {
    "sender": {
      "sender_id": {"open_id": "ou_xxx", "user_id": "xxx"}
    },
    "message": {
      "chat_id": "oc_xxx",
      "content": "{\"text\":\"开始 编写文档\"}",
      "message_id": "om_xxx"
    }
  }
}
```

## 5. 配置项

| 环境变量 | 必填 | 说明 |
|---|---|---|
| `LARK_APP_ID` | 是 | 飞书应用 App ID |
| `LARK_APP_SECRET` | 是 | 飞书应用 App Secret |
| `LARK_BITABLE_APP_TOKEN` | 是 | 多维表格 app_token |
| `LARK_CLIENTS_TABLE_ID` | 是 | clients 表 table_id |
| `LARK_PROJECTS_TABLE_ID` | 是 | projects 表 table_id |
| `LARK_TAGS_TABLE_ID` | 是 | tags 表 table_id |
| `LARK_TIME_ENTRIES_TABLE_ID` | 是 | time_entries 表 table_id |
| `LARK_NOTIFY_CHAT_ID` | 否 | 群聊 chat_id，用于推送 |
| `HOST` | 否 | 服务器监听地址，默认 0.0.0.0 |
| `PORT` | 否 | 服务器监听端口，默认 8000 |
| `DEBUG` | 否 | 调试模式，默认 false |
| `TIMEZONE` | 否 | 时区，默认 Asia/Shanghai |

## 6. 飞书权限清单

| 权限 | 权限标识 | 用途 |
|---|---|---|
| 多维表格 | `bitable:app` | 查看、评论、编辑和管理多维表格 |

| 通讯录 | `contact:user.base:readonly` | 获取用户基本信息（团队看板需要） |
