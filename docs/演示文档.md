## 一、产品定位

在飞书生态内复现 Toggl Track 的核心能力，作为多维表格插件上架，**零服务器、零备案、零运维**。

| 维度 | 说明 |
|---|---|
| 部署形态 | 飞书多维表格插件 + 飞书云函数 |
| 数据存储 | 飞书多维表格（4 张表） |
| 交互入口 | 多维表格插件 + 飞书消息机器人 |
| 运维成本 | ¥0（飞书全托管） |
| 上架审批 | 飞书插件市场审核 3-5 天 |

## 七、演示流程

### 演示 1：创建项目并开始计时

1. 打开飞书多维表格 → 进入时间追踪插件
2. 点"项目管理" → 新建项目"工签办理"，客户选"XX 公司"
3. 回到"计时器"页 → 点"开始计时" → 描述填"准备工签材料" → 项目选"工签办理"
4. 等待 10 秒 → 点"停止"
5. 在多维表格时间条目表看到这条记录

### 演示 2：查看报表并导出

1. 打开"报表分析"页
2. 时间范围选本周 → 点"生成报表"
3. 看到总工时、条目数、项目数、标签数
4. 看到按日期柱状图、按项目饼图、按标签饼图
5. 点"导出飞书文档" → 飞书里打开生成的云文档

### 演示 3：机器人指令计时（待 #8 配通）

1. 在飞书群 @时间追踪机器人
2. 发"开始 测试"
3. 机器人回复"计时已开始，描述：测试"
4. 发"停止"
5. 机器人回复"计时已停止，时长 00:05:23"
