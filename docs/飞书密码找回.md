# 飞书密码找回

## 使用步骤

1. 在登录页点击“忘记密码”，然后点击“通过飞书验证身份”。已登录用户可从“设置 → 修改密码 → 忘记原密码？通过飞书重置”进入。
2. 使用此前已绑定的网站账号对应的飞书身份完成验证。
3. 核对显示的登录用户名，输入两次新密码。新密码为 12–256 个字符，验证凭证有效期为 5 分钟。
4. 成功后返回登录页，使用新密码登录。旧会话在下一次服务端身份检查时失效。

未绑定飞书、绑定重复或账号停用时，无法使用此方式找回，需要联系维护人员。不要清空用户表的密码字段或填写明文密码。

## 维护说明

- 前端与 `frontend/api-deploy/auth.cjs` 必须配套发布；本次实现未变更用户表结构。
- 复用现有飞书 OAuth 回调地址及应用配置。账号由服务端换取的飞书身份唯一确定，不接受浏览器指定重置对象。
- 重置凭证与登录凭证用途隔离，仅保存在当前页面内存。刷新后需重新验证。
- 凭证绑定当前密码与飞书绑定版本；更新密码、变更绑定或停用账号后拒绝旧凭证。密码使用现有 scrypt 哈希格式保存。
- 服务端设置无缓存响应、每实例频率上限与同账号并发保护。跨实例同时提交的原子一致性受多维表格写入能力限制。
- 网络结果不明确时，可先用新密码尝试登录；必要时重新验证飞书，不要持续重复提交。

## 验证

自动化测试覆盖凭证用途隔离、过期、重放、旧会话失效、非目标账号保护、停用账号、缺失及重复绑定、绑定变更和密码哈希验证。浏览器测试模拟飞书回调，覆盖入口、两次密码校验、提交和返回登录；未对真实用户执行密码重置。真实飞书授权需配套发布后验证。
