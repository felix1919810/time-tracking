# 当前中文网站

当前维护入口为本目录。`src/` 是 Vue 页面，`api-deploy/` 是对应的腾讯云 SCF Express 服务。仓库根目录另有早期前端、后端及发布产物，不能混用。

## 在线验收版（2026-09-06）

地址：<https://felix1919810.github.io/time-tracking/preview-20260906/>。

设置页新增「外观」，可切换深色/浅色模式，立即生效并保存在当前浏览器，刷新后恢复。未选择时默认深色。

## 中英文版本（2026-09-07）

登录页、侧栏和设置页可切换简体中文/English，立即生效且不刷新页面、不重置正在进行的计时。语言与主题分别保存在当前浏览器。

- 固定界面词条位于 `src/locales/zh.json`、`en.json`。词条使用中文原文作为键，带变量的整句使用 `{0}` 等占位符。
- `src/locales/countries.json` 预制了飞书国家表 200 个国家的中英文名称，按国家代码关联。选择器支持中文、英文和代码检索；提交仍使用原国家名称。
- 自定义分类、标题、备注通过现有后端 `/translate` 调用百度，支持中英双向显示。前端对相同原文/目标语言去重和缓存、最多并发 2 个请求，切换账号清空缓存。翻译失败保留原文，短暂冷却后允许重试。
- 设置中的「显示任务内容原文」可关闭动态翻译显示。编辑始终使用原文；分类和统计仍按原始值处理；CSV 导出保留内容原文，列名跟随界面语言，导入兼容中英文列名。
- 后端 `api-deploy/translation.cjs` 使用环境变量 `BAIDU_APP_ID`、`BAIDU_KEY`，保留多行结果，限制输入长度、排队限速并缓存成功结果。配置缺失或翻译不可用时，页面回退原文。

验证：22 项自动测试、生产构建的中文回归与 `npm run test:i18n` 通过。中英文浏览器验收覆盖三种角色、页面切换、原文编辑、国家值、CSV、缓存、翻译失败和运行中计时。线上百度双向翻译、多行备注与健康检查已验证。验收地址沿用上方链接。

原首页保留。验收版连接原有腾讯云后端和真实工时数据，可先用原账号密码登录；预览路径的飞书授权回调尚未验证。腾讯云 SCF 默认域名和 COS 默认域名均返回 `Content-Disposition: attachment`，浏览器会下载页面，因此网页入口使用 GitHub Pages。

SCF 后端已同步本轮修复，并保留云端原有静态托管、JSAPI 与旧翻译接口。当前中文界面未接入多语言。此入口文件中的应用密钥已改为云端环境变量；历史文件中的凭证和权限体系仍待后续治理。

## 本地运行与检查

```powershell
cd frontend
npm ci
npm run dev
npm test
npm run build
```

默认开发地址：`http://localhost:5173/time-tracking/`。默认 API 仍是既有 SCF 服务；真实页面操作会调用它。本轮自动测试全部使用模拟接口，不修改线上记录。

可在 `.env.local` 中设置 `VITE_API_BASE` 为其他 API 的完整源地址。此项是公开的前端配置，不能存放密钥。

## 两种构建路径

- GitHub Pages：默认 `npm run build`，资源前缀为 `/time-tracking/`。
- COS 根目录：`npm run build -- --base=/`，上传该次生成的 `dist/`。也可设置 `VITE_BASE_PATH=/`。

只执行构建不会发布。不要直接上传之前遗留在 `api-deploy/public/` 或 `gh-pages-deploy/` 的旧包。前端可独立验证；**分页修复上线前必须先部署本目录的 SCF 后端**，确保 `/entries` 返回 `page_token`。旧后端遇到多页数据时，新前端会提示分页不完整，不会把前 500 条假装成全部数据。

SCF 的 `scf_bootstrap` 必须使用 LF 换行并在 ZIP 内保留可执行权限。Windows 打包时按字节写入启动文件，不能使用会自动转换换行的文本输出。已添加 `.gitattributes` 约束源码换行；部署归档仍须检查实际字节和权限。

## 浏览器回归

`npm test` 使用 Node 内置测试，无需连接飞书。

`npm run test:browser` 需要先启动本地开发服务，并安装 Playwright 与浏览器。默认使用 Edge；其他环境可设置 `BROWSER_CHANNEL`。若 Playwright 来自外部运行时，设置 `PLAYWRIGHT_MODULE_PATH` 为该包的绝对目录。可以用 `TEST_SITE` 指定本地预览地址。

浏览器测试屏蔽真实外部网络，模拟 501 条工时与读写失败，输出到仓库根目录 `artifacts/`。它验证六个页面、分页、即时计时、停止重试、删除回滚、账号隔离、侧栏布局与坏缓存恢复。
