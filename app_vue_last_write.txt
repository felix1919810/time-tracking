  <!-- 计时数据流说明 -->
  <div class="flow-section">
    <h2>🔄 计时数据流（核心流程）</h2>

    <div class="flow-step">
      <div class="step-num">1</div>
      <div class="step-content">
        <strong>用户点击"开始计时"</strong> → 计时器横条触发 <code>pendingStartTimer</code>，WeekView 弹出计时表单（描述 / 分类 / 国家）
      </div>
    </div>

    <div class="flow-step">
      <div class="step-num">2</div>
      <div class="step-content">
        <strong>填写后点"开始"</strong> → <code>startActiveTimer(payload)</code> 在 App.vue 设置全局 <code>activeTimer</code> ref，记录 <code>startTime = Date.now()</code>，启动 1 秒跳动定时器
      </div>
    </div>

    <div class="flow-step">
      <div class="step-num">3</div>
      <div class="step-content">
        <strong>横条显示实时时长</strong> → <code>timerElapsedText</code> 计算属性每秒更新 <code>HH:MM:SS</code> 或 <code>MM:SS</code> 格式
      </div>
    </div>

    <div class="flow-step">
      <div class="step-num">4</div>
      <div class="step-content">
        <strong>用户点"完成"</strong> → <code>stopActiveTimer()</code> 构造 fields（含 ISO 时间戳），POST <code>/entries</code> 到 SCF
      </div>
    </div>

    <div class="flow-step">
      <div class="step-num">5</div>
      <div class="step-content">
        <strong>SCF 后端转换</strong> → <code>lark()</code> 函数把 ISO 字符串转成毫秒时间戳，手动 JSON.stringify 后调用飞书 API
      </div>
    </div>

    <div class="flow-step">
      <div class="step-num">6</div>
      <div class="step-content">
        <strong>飞书多维表格写入</strong> → 工时表新增一条记录，返回 <code>record_id</code>，前端 <code>loadEntries()</code> 刷新周视图
      </div>
    </div>

    <div class="flow-step">
      <div class="step-num">7</div>
      <div class="step-content">
        <strong>页面刷新恢复</strong> → <code>activeTimer</code> 持久化到 <code>localStorage('tt_active_timer')</code>，刷新后恢复跳动，点"完成"才写入
      </div>
    </div>
  </div>

  <!-- 查询数据流 -->
  <div class="flow-section">
    <h2>📖 查询数据流（周视图 / 仪表盘 / 报表）</h2>

    <div class="flow-step">
      <div class="step-num">1</div>
      <div class="step-content">
        <strong>页面 onMounted</strong> → 调用 <code>loadEntries()</code> / <code>loadData()</code>
      </div>
    </div>

    <div class="flow-step">
      <div class="step-num">2</div>
      <div class="step-content">
        <strong>前端构造查询</strong> → <code>GET /entries?page_size=500</code>
        <br>• admin 账号：不加 user filter，看所有数据
        <br>• user 账号：加 <code>&user=displayName</code>，只看自己的数据
      </div>
    </div>

    <div class="flow-step">
      <div class="step-num">3</div>
      <div class="step-content">
        <strong>SCF 转发到飞书</strong> → 带 <code>filter=CurrentValue.[user]="xxx"</code> 调飞书 Bitable API
      </div>
    </div>

    <div class="flow-step">
      <div class="step-num">4</div>
      <div class="step-content">
        <strong>前端渲染</strong> → <code>entries.value = data.items</code>，周视图按本地日期分组，仪表盘用 Chart.js 画图，报表用表格展示
      </div>
    </div>
  </div>

  <!-- 关键技术点 -->
  <div class="flow-section">
    <h2>🔧 关键技术决策</h2>
    <table>

        <tr>
          <th>问题</th>
